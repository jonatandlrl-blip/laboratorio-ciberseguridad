
# Herramientas OSINT

## Objetivo
Documentar las herramientas que estoy aprendiendo a utilizar para realizar investigaciones con fuentes abiertas.

## Maltego
Herramienta que permite representar visualmente relaciones entre entidades y datos mediante grafos.

## theHarvester
Herramienta utilizada para recopilar información pública sobre dominios, como direcciones de correo y nombres de hosts, según las fuentes consultadas.

## Maigret
Permite buscar nombres de usuario en diferentes sitios web para identificar posibles perfiles públicos asociados.

## Hunchly
Herramienta de apoyo a investigaciones web que permite capturar y organizar páginas consultadas como evidencias.

## Buenas prácticas
- Trabajar con objetivos ficticios o investigaciones autorizadas.
- Registrar las fuentes consultadas y la fecha de recopilación.
- Verificar los hallazgos antes de extraer conclusiones.
- Diferenciar hechos confirmados de hipótesis.
- Proteger los datos personales y las evidencias sensibles.

## Estado de aprendizaje
Este documento se actualizará a medida que avance en el uso práctico de cada herramienta.
