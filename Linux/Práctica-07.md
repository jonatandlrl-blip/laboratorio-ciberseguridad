# Práctica 07: Introducción a Git y GitHub

## Objetivo
Comprender cómo se registran los cambios y se documenta el trabajo técnico mediante Git y GitHub.

## Conceptos básicos
- Repositorio: espacio donde se almacena un proyecto.
- Commit: registro de un cambio realizado.
- Rama (branch): línea de trabajo independiente.
- README: archivo que explica el contenido de un proyecto.
- Markdown: formato de texto utilizado para documentar información.

## Actividades realizadas
- Creación de un repositorio público.
- Organización de prácticas en carpetas.
- Creación y edición de archivos Markdown.
- Registro de cambios mediante commits.
- Documentación del aprendizaje en ciberseguridad y OSINT.

## Observaciones
GitHub permite conservar un historial de cambios y mostrar proyectos técnicos como parte de un portfolio profesional.
