# Práctica 02: Gestión de archivos y directorios en Linux

## Objetivo
Aprender a identificar, crear, copiar, mover y eliminar archivos y directorios.

## Comandos estudiados
- `pwd`: muestra el directorio actual.
- `ls`: muestra los archivos y directorios.
- `cd`: permite cambiar de directorio.
- `mkdir`: crea directorios.
- `touch`: crea archivos vacíos.
- `cp`: copia archivos.
- `mv`: mueve o renombra archivos.
- `rm`: elimina archivos.
