# Práctica 05: Redes básicas en Linux

## Objetivo
Conocer los comandos básicos para consultar la configuración de red y comprobar la conectividad.

## Conceptos básicos
- Dirección IP: identifica un dispositivo dentro de una red.
- Interfaz de red: conexión de red física o virtual.
- DNS: sistema que traduce nombres de dominio a direcciones IP.
- Puerta de enlace: dispositivo que permite comunicarse con otras redes.

## Comandos estudiados
- `ip addr`: muestra las direcciones IP de las interfaces.
- `ip route`: muestra las rutas de red.
- `ping`: comprueba la conectividad con otro equipo.
- `getent hosts`: consulta la resolución de nombres.
- `ss -tuln`: muestra los puertos en escucha.

## Observaciones
Registrar los comandos utilizados y los resultados obtenidos. Realizar las comprobaciones únicamente en redes propias o autorizadas.
