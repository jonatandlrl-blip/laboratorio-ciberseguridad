# Práctica 03: Permisos y usuarios en Linux

## Objetivo
Comprender cómo se gestionan los permisos de archivos y directorios en Linux.

## Conceptos básicos
- Usuario: cuenta que utiliza el sistema.
- Grupo: conjunto de usuarios con permisos comunes.
- Lectura (r): permite consultar un archivo.
- Escritura (w): permite modificar un archivo.
- Ejecución (x): permite ejecutar un archivo o acceder a un directorio.

## Comandos estudiados
- `whoami`: muestra el usuario actual.
- `id`: muestra la identidad y los grupos del usuario.
- `ls -l`: muestra los permisos de archivos y directorios.
- `chmod`: modifica los permisos.
- `chown`: cambia el propietario de un archivo.

## Objetivo

Aprender a crear, organizar y gestionar directorios en Linux.

## Comandos utilizados

- `pwd`: consultar la ubicación actual.
- `ls`: listar el contenido de un directorio.
- `mkdir`: crear directorios.
- `cd`: acceder a otros directorios.
- `rmdir`: eliminar directorios vacíos.
- `find`: buscar archivos y directorios.
