# Práctica 01: Introducción a Linux

## Objetivo
Documentar el aprendizaje y las prácticas realizadas en el entorno Linux.

## Prácticas
- Comandos básicos de Linux.
- Gestión de archivos y directorios.
- Administración básica del sistema.
- Documentación de resultados y aprendizaje.

- ## Comandos utilizados

- `pwd`: muestra la ruta del directorio actual.
- `ls`: muestra los archivos y directorios.
- `cd`: permite cambiar de directorio.
- `whoami`: muestra el nombre del usuario actual.
- `uname -a`: muestra información del sistema operativo y del kernel.

Estos comandos permiten conocer el entorno Linux y realizar comprobaciones básicas de navegación e identificación del sistema.

## Resultados

Se han documentado cinco comandos básicos de Linux para consultar el directorio actual, listar archivos y directorios, cambiar de directorio, identificar al usuario actual y obtener información del sistema.

Los resultados de su ejecución se incorporarán a partir de las comprobaciones realizadas en el terminal.
