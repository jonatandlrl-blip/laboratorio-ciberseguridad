# Prácticas de Linux

Documentación de prácticas y aprendizaje del entorno Linux, comandos básicos y administración del sistema.

## Prácticas disponibles

- Práctica 01: Introducción a Linux.
- Práctica 02: Comandos y gestión de archivos.
- Práctica 03: Trabajo con directorios.
- Práctica 04: Permisos y administración básica.
- Práctica 05: Usuarios y grupos.
- Práctica 06: Procesos y servicios.
- Práctica 07: Repaso y documentación.

## Objetivo

Documentar los ejercicios realizados, los comandos utilizados y los resultados obtenidos.
